Study MBBS Abroad - Landing Page

Project Overview:

This is a responsive landing page designed for the "Study MBBS Abroad" campaign. The webpage provides key information about studying MBBS in various countries, eligibility criteria, and an application form.

Features:

Hero Section: Engaging banner with a CTA button ("Apply Now for MBBS Abroad").

Why Study MBBS Abroad?: Lists key benefits.

Top Countries: Highlights Russia, Uzbekistan, Kazakhstan, Philippines, Georgia, Kyrgyzstan, and Egypt.

Admission Process & Eligibility: Step-by-step guide on applying.

Call-to-Action (CTA) Form: Collects user details (name, email, phone, country preference).

Fully Responsive: Optimized for mobile, tablet, and desktop views.

🛠 Technologies Used

HTML: Structure of the webpage.

CSS (Tailwind/Bootstrap): Styling and responsiveness.

JavaScript: Form validation and tracking integration.
